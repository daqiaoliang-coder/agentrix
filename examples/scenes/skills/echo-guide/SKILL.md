# Echo Guide

本技能说明 `echo` 工具的调用方式。执行前请先阅读 `references/contract.md` 了解参数与错误语义。

## 使用步骤

1. 确认用户希望被原样复述的文本片段。
2. 调用 `echo` 工具，参数为 `{"content": "<原文>"}`。
3. 将工具返回的文本作为最终回复，不要额外加工。

## 错误处理

- 参数缺失：补齐 `text` 后重试一次。
- 工具超时：告知用户当前不可用，并建议稍后重试。
