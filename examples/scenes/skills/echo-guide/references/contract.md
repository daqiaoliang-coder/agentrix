# echo 工具参数契约

## 输入

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `content` | string | 是 | 需要原样回显的文本 |

示例：

```json
{"content": "你好，Agentrix"}
```

## 输出

返回纯文本 `echo: <content>`：

```
echo: 你好，Agentrix
```

## 错误语义

- `content` 缺失或参数不是合法 JSON：工具返回参数错误，模型应修正后重试。
- 调用超时：由工具超时包装器统一处理，模型会收到超时说明，可决定降级回复。
